## 🛠️ How to Customize

### Edit Your Information

1. **Change your name**: Open `index.html` and replace "Taib" with your name
2. **Update about section**: Edit the text in the "About Me" section
3. **Modify projects**: Update the project cards with your own projects
4. **Add social links**: Update the URLs in the Contact section (GitHub, email, Twitter, LinkedIn)

### Colors & Styling

Edit the CSS variables in `styles.css` (lines 11-18):

```css
:root {
    --primary-color: #6366f1;    /* Change primary color */
    --secondary-color: #ec4899;  /* Change secondary color */
    /* ... other colors ... */
}
```

### Add Your Profile Picture

Replace the icon with an image:

```html
<!-- In index.html, replace the hero-avatar section -->
<div class="hero-avatar">
    <img src="path-to-your-image.jpg" alt="Profile Picture">
</div>
```
